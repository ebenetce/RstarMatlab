# Laubach-Williams 2023 (LW2023)

`LW2023` implements the current COVID-adjusted Laubach-Williams
specification.

## Input data

Provide the LW variables plus a quarterly date variable and `covid.ind`:

* `date`, `Date`, `time`, or `Time`
* `gdp.log`
* `inflation`
* `inflation.expectations`
* `oil.price.inflation`
* `import.price.inflation`
* `interest`
* `covid.ind`

Tables and timetables are supported. Dates must be sorted, complete quarterly
observations. The model needs an eight-quarter presample.

## Reproduce the current New York Fed vintage

```matlab
dataUrl = "https://www.newyorkfed.org/medialibrary/media/research/economists/williams/data/Laubach_Williams_current_estimates.xlsx";
data = readtable(dataUrl, Sheet="input data", VariableNamingRule="preserve");
results = rstar("LW2023", rstarOptions("LW2023")).estimate(data);
dates = data.Date(9:end);

figure(Color="white")
hold on
plot(dates, results.stage3.rstarFiltered, LineWidth=2, DisplayName="Natural rate")
plot(dates, results.stage3.trendFiltered, LineWidth=2, DisplayName="Trend growth")
title("Current U.S. Laubach-Williams estimates")
xlabel("Quarter")
ylabel("Percent")
xlim([datetime(1985,1,1), dates(end)])
ylim([0, 4])
grid on
box on
legend(Location="southwest")
```

Set `SampleStart` or `SampleEnd` in `options` to restrict the estimation
sample. If unset, the model uses the earliest feasible start and final
available quarter.
